# Titanic-survival-prediction-
A decision tree model trained to predict if a person will survive the titanic or not using the given a given set of data.
It was trained in kaggle using the given datasets.
The datasets are namely test and train_selected.
The list of categories given in the datasets had name, sex, ticket number, fare, etc
The repository has 2 files and the former one is the report comprising of the summary of the whole process
The latter one is the notebook in which the ML model was trained
